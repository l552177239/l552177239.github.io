Markdown 语法

什么是Markdown语法？

Markdown是一种可以使用普通文本编辑器编写的标记语言，通过简单的标记语法，它可以使普通文本内容具有一定的格式。Markdown是一种轻量级标记语言，目标是实现「易读易写」
