因为 axios 不能进行文件的直接进行请求发送，这样我们需要利用 form 来进行数据传输

为了更灵活的发送表单数据（当然也可以用<form>标签进行包裹）我们需要声明一个新的 FormData对象

调用 formData 的 append() 方法进行添加文件
