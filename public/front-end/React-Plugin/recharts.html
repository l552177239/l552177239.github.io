Recharts

Recharts是使用React和D3构建的重新定义的图表库，主要原则有

  1. 声明式的标签，让写图表和写 HTML 一样简单

  2. 贴近原生 SVG 的配置项，让配置项更加自然

  3. 接口式的 API，解决各种个性化的需求
